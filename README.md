# تراز (Taraz)

اپلیکیشن حسابداری شخصی اندروید با رابط راست‌به‌چپ و تمرکز بر ثبت و مدیریت درآمد، هزینه، مانده و ورود تراکنش از متن پیامک بانکی.

## قابلیت‌های نسخه فعلی

- داشبورد مالی با مانده، درآمد و هزینه
- ثبت و مشاهده تراکنش‌ها
- ذخیره‌سازی محلی تراکنش‌ها
- تحلیل اولیه متن پیامک و استخراج مبلغ
- رابط RTL و طراحی نزدیک به تصاویر مرجع
- GitHub Actions برای ساخت APK

## Build

پروژه با Android Gradle Plugin 8.7.3 و Kotlin 2.0.21 ساخته شده است. Workflow در هر push به `main` نسخه Debug APK را می‌سازد و با نام `taraz-debug-apk` به‌عنوان Artifact منتشر می‌کند.

## نکته

نسخه فعلی پایه عملیاتی پروژه است و برای تکمیل مرحله بعد، ماژول‌های بودجه، حساب‌ها/کارت‌ها، گزارش‌های نموداری و موتور دقیق‌تر تشخیص پیامک بانکی باید توسعه داده شوند.
